## 🖼️ 如何替换为自己的图片

### 方法1：使用本地图片（推荐）

1. 将你的图片文件放到这个目录：`public/images/hero/`
2. 建议的文件名格式：
   - `hero-1.jpg` 或 `hero-1.png`
   - `hero-2.jpg` 或 `hero-2.png`
   - `hero-3.jpg` 或 `hero-3.png`
   - `hero-4.jpg` 或 `hero-4.png`

3. 修改 `app/page.tsx` 文件中的图片路径：

```typescript
const heroImages = [
  '/images/hero/hero-1.jpg',  // 替换为你的图片
  '/images/hero/hero-2.jpg',
  '/images/hero/hero-3.jpg',
  '/images/hero/hero-4.jpg',
];
```

### 方法2：使用在线图片URL

如果你有在线图片链接，直接在 `app/page.tsx` 中替换URL即可。

## 📐 图片规格建议

### 尺寸
- **推荐尺寸**：1920×1080 像素 (16:9 比例)
- **最小尺寸**：1280×720 像素
- **最大文件大小**：建议每个图片不超过 2MB

### 格式
- **推荐格式**：JPEG (压缩好，适合照片)
- **也可使用**：PNG、WebP
- **不建议**：GIF（动画效果在轮播中表现不佳）

### 内容建议
1. **真实训练场景**：展示实际的陆上训练动作
2. **专业教练形象**：增加可信度
3. **训练基地环境**：千岛湖龙川湾训练基地实景
4. **学员训练画面**：展示课程的实际效果

### 技术要求
- 图片需要有一定的暗度，因为会有深色遮罩层覆盖
- 或者使用 Lightroom/Photoshop 将图片调暗一些
- 确保文字在图片上清晰可读

## 🎨 视觉效果说明

当前的轮播组件会自动添加：
- **淡入淡出效果**：每张图片之间平滑过渡
- **深色遮罩**：确保白色文字清晰可读
- **渐变背景**：蓝色系渐变遮罩
- **轮播指示器**：底部的圆点指示器
- **左右箭头**：用户可以手动切换图片

## ⏱️ 轮播设置

当前设置：
- **自动轮播间隔**：6秒
- **过渡动画时长**：1秒
- **支持手动切换**：点击圆点或箭头

如需修改，编辑 `app/page.tsx`：

```typescript
<ImageCarousel images={heroImages} interval={6000} />  // 6000 = 6秒
```

## 🚨 注意事项

1. **图片版权**：确保你有权使用这些图片
2. **加载速度**：图片大小影响网站加载速度
3. **移动端适配**：确保图片在手机上也能良好显示
4. **内容一致性**：所有图片应该保持风格一致

## 📱 测试建议

1. 在不同设备上测试（手机、平板、电脑）
2. 检查不同网络环境下的加载速度
3. 确保文字在所有图片上都清晰可读
4. 测试轮播功能是否正常工作
