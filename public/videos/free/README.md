# 视频文件放置说明

## 免费预览视频（前20%）

请将以下预览视频文件放置在此目录下：

- `frog-preview.mp4` - 蛙泳陆上训练预览视频（约3分钟）
- `freestyle-preview.mp4` - 自由泳陆上训练预览视频（约3分钟）
- `combo-preview.mp4` - 组合训练预览视频（约6分钟）

## 视频格式要求

- 格式：MP4 (H.264 编码)
- 分辨率：建议 1920x1080 或 1280x720
- 文件大小：建议控制在 50MB 以内（预览视频）

## 视频录制建议

1. 预览视频包含课程开头和前20%内容
2. 加入课程介绍和训练重点说明
3. 每个预览视频时长约3-6分钟
4. 确保视频清晰度和音质良好

## 视频处理工具推荐

- HandBrake（免费开源视频转码工具）
- Adobe Premiere Pro
- Final Cut Pro
- 在线工具：CloudConvert

## 注意事项

- 预览视频需要让用户了解课程风格和价值
- 不要展示完整的训练内容
- 确保视频可以流畅播放
