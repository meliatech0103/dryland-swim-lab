# 付费完整视频放置说明

## 完整课程视频

请将以下完整视频文件放置在此目录下：

- `frog-full.mp4` - 蛙泳陆上训练完整视频（15分钟）
- `freestyle-full.mp4` - 自由泳陆上训练完整视频（15分钟）
- `combo-full.mp4` - 组合训练完整视频（30分钟）

## 视频格式要求

- 格式：MP4 (H.264 编码)
- 分辨率：建议 1920x1080 或 1280x720
- 文件大小：建议控制在 200MB 以内

## 视频内容结构

1. **课程介绍**（1-2分钟）
   - 教练自我介绍
   - 课程目标和训练重点
   - 适合人群说明

2. **热身环节**（3-5分钟）
   - 陆上热身动作
   - 关节活动
   - 激活肌肉

3. **核心训练**（8-12分钟）
   - 专项训练动作详解
   - 动作演示
   - 常见错误纠正

4. **拉伸放松**（2-3分钟）
   - 训练后拉伸动作
   - 放松技巧
   - 下次训练建议

## 密码系统说明

用户购买课程后，会收到一个解锁密码（当前测试密码）：
- 蛙泳课程：FROG2025

## 视频处理工具推荐

- HandBrake（免费开源视频转码工具）
- FFmpeg（命令行工具）
- Adobe Media Encoder

## 注意事项

1. 确保视频版权清晰
2. 考虑视频加载速度，适当压缩
3. 添加字幕或讲解文字
4. 确保视频质量和音质良好
5. 测试视频在不同网络环境下的播放效果

1. 在 Creem.io 创建产品
2. 配置发货邮件模板（包含密码）
3. 在 `lib/lessons.ts` 中更新 `creemLink`
4. 测试完整购买和解锁流程
